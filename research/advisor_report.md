# method4 之后的研究脉络与决策范式转变

> 涵盖 Round 9→12 + 落地验证；并解释**为什么放弃了早期的"贝叶斯决策"与"反事实记忆"**两条路线。
> 详见 `method4-7.md` / `finish4-7.md` / `decision_methods_compare.md` / `test/`。

---

## 0. 一句话主线

> **从"造一个更好的模型路由器"，转向"研究一个自适应 agent 何时该行动、何时该退、凭什么相信自己的判断"。**
> 核心诚实结论：强 base 模型（Rocket/Chronos-2）在 benchmark 上已**饱和**，最优决策大多是"诚实守 base"；
> 系统的价值不在提分，而在**风险可控的选择性弃权（risk-controlled selective abstention）**。

## 1. method4 之后的四轮演进（Round 9→12）

| 轮次 | 研究对象 | 做法 | 关键发现 | 结论 |
|---|---|---|---|---|
| **R9 / method4** | learned belief（学出来的信念）| `b(M\|z)=softmax(g_φ(z))`，CE 到 oracle-winner；belief-margin 门控 | **F-R9.2 belief inversion**：信念强度是**反指标**（偏离错时 0.79 > 对时 0.51）；F-R9.5 换更强 embedding 反而更糟；**F-R9.7/9.8 Rocket 在 UCR 71% / UEA 75% cell 就是 oracle** | learned belief 不是银弹；**真瓶颈是 benchmark 饱和 + 校准缺失**，不是表示力 |
| **R10 / method5** | saturation detection（该不该选）| 不再选模型，改回归 oracle-gap ĝ(z) → gap 小则 abstain | F-R10.1 saturation 部分可检测（fc corr 0.37 / clf 0.16）；**F-R10.2 gate = 单调损害控制**；**F-R10.3 仍无正增益——瓶颈是 routing 执行（per-cell winner 不可学），跨饱和/未饱和域普遍** | 能判断"有没有头寸"，但把头寸**变现**仍卡在 per-cell 预测 |
| **R11 / method6** | 决策机制：trust ≠ confidence | 解耦"选谁(confidence)"与"信不信这次(trust)"；扩候选库；conformal trust | **F-R11.4 扩库 5→10 直接 un-saturate**（rocket-是-oracle 71%→38%，gap→5.87pp）；**F-R11.5 conformal Trust-AUC 0.796**；**F-R11.7 trust 只避险不获利** | trust 是**风险估计器 ≠ 效用估计器**；避险闭环成立 |
| **R12 / method7** | gain 能不能学 | 回归 gain、组合、proposal net、探索 6 个方向 | F-R12.1/12.2 **gain 逐-cell 不可可靠预测**（corr 0.40 但"是否获利"AUC 0.47；预测域 17% 头寸也吃不到）；**F-R12.5 避险↔conformal(0.79)、获利↔saturation(0.71)，是不同信号、朴素融合反而稀释** | 决策升级为**双信号解耦**：`deviate iff conformal_safe AND saturation_headroom` |

**主线收敛**：learned belief 证伪 → saturation 检测 → trust 只避险 → **避险↔conformal / 获利↔saturation 双信号解耦**。

## 3. 先验/后验的失败，与双信号机制为什么对

### 3.1 讲清"先验 / 后验 / 贝叶斯决策"

我们要做的决策是：**面对一个新任务（少量样本），要不要离开默认的强模型 base、改用某个候选模型？**

早期用的是**贝叶斯**这套思路，三个词：

- **先验**：还没看这个具体任务前，凭历史经验的"直觉"——"一般来说哪个模型更靠谱"。
- **证据（似然）**：看这个任务给的几十个样本（比如交叉验证 CV 的表现）。
- **后验**：把"直觉"和"这次的证据"合起来，算出一个概率分布 `b(M)`——"**我觉得哪个模型会赢**"。
- **贝叶斯决策**：就按后验最高的那个模型去选（或按后验做 Thompson 随机采样）。

听起来很合理。问题是**实测下来，这套在我们的场景里会坑**，原因有三个。

### 3.2 后验为什么会失败

**① 后验是"反指标"——模型越笃定，越容易错（F-R9.2）。**
打个比方：一个考前押题特别自信的学生，他押得最有把握的，往往是他**背得最熟的那类套路题**；
可一旦考试换了出题分布，他恰恰在最自信的地方翻车。
我们的后验也是这样：它的高置信对应的是**训练里见得最多的"套路"**，不是"这次真的对"。
实测：偏离做错时后验平均 **0.79**，做对时反而只有 **0.51**——越自信越错。
贝叶斯决策的前提是"相信后验"，但在这里**相信后验=主动受害**。

**② 想靠"更好的先验/更强的特征"救它，反而更糟（F-R9.5）。**
我们换了更强的 512 维表示去喂这个后验，结果它变得**更尖锐也更错**（−0.80pp 恶化到 −3.96pp）。
原因：我们只有几十到一百多个历史任务（cell）来学"谁会赢"——**元任务的训练数据太少**。
数据这么少，后验必然过拟合；特征越强，它把噪声也学得越狠。**先验再精，也救不了"样本太少+证据有噪声"。**

**③ 任务已经"饱和"，后验算了也白算。**
base 模型（Rocket / Chronos-2）在这些 benchmark 上已经几乎是最优了——**正确答案 99% 就是"别动、守 base"**。
在一个"标准答案恒定"的考试上，再精密的贝叶斯机器也没有用武之地（后验最后都会坍缩回 base）。

### 3.3 关键转变：把"置信度"和"可信度"分开

贝叶斯只给了一个数——**置信度 confidence**（"我觉得是 A"有多强）。
但它没回答另一个更重要的问题——**可信度 trust**（"我这次的判断，到底该不该被信"）。

> 类比：一个民科可以**非常自信**（置信度高），但他的话**完全不该被信**（可信度低）。
> 贝叶斯把这两件事混成了一个数，于是被"自信但不可信"的判断带沟里。

所以我们不再去优化"那个会反噬的后验"，而是**把决策拆成两个独立的问题**。

### 3.4 当前的双信号机制

"要不要偏离 base"其实暗含**两个不同的问题**，要用**两个不同的信号**分别回答：

| 问题 | 大白话 | 用什么信号 | 直觉 |
|---|---|---|---|
| **会不会变差？（避险）** | 偏离了，会不会反而更糟？ | **conformal**（一致性/符合度）| 看"这个新任务和我历史见过的任务**像不像**"。像→我的判断可信；不像(没见过的 OOD)→别冒险，守 base。 |
| **值不值得动？（获利）** | 就算安全，换模型真能多赚吗？ | **saturation headroom**（饱和余量）| 预测"最好的候选比 base 能高多少"。空间大→值得试；空间≈0(饱和)→守 base。 |

**决策规则：两个都过才偏离**——`偏离 ⟺ conformal 说安全 AND saturation 说有空间`，否则守 base。

为什么一定要**两个分开**、不能揉成一个万能分数？因为实测发现（F-R12.5）：
**conformal 最会判"会不会变差"（AUC 0.79）、saturation 最会判"值不值得动"（AUC 0.71），但两者在对方的问题上都很弱**；
硬把它们融成一个分数，结果**两边都被稀释、都变差**。所以正确做法是"**用对的信号干对的事**"。

> 一句话对比：
> **贝叶斯** = 完全相信"一个很自信的专家"的单一判断（而这个专家被证明是越自信越容易错）；
> **双信号** = 先问"这事在不在专家熟悉的范围内"（可信度/conformal），再问"这事到底值不值得折腾"（收益空间/saturation），
> **两关都过才动手**——这才像一个**谨慎、会自我怀疑**的决策者。

而 conformal 之所以能补上贝叶斯的坑：它**不看模型自己有多自信**，而是用"新任务离历史分布有多远"来算可信度——
是**分布无关、天然校准**的，恰好治住了"后验过度自信"这个病根（实测 conformal Trust-AUC 0.80 ≫ 看模型内部分歧的 0.55）。

## 4. 为什么偏离"贝叶斯决策"

早期范式（method3 及之前）：energy-based **bayesian_router** —— 学一个候选模型的**后验信念** `b(M)`，
用 Thompson / argmax / risk-min 等 decide-mode 从后验采样/取点决策（外加 meta-bandit 在 decide-mode 间切换）。

**放弃的三条实证理由**：

1. **后验本身被证伪是"反指标"（F-R9.2）**。learned belief 的强度与正确性**负相关**——后验越自信，偏离越容易错。
   贝叶斯决策的前提是"信后验"，但这里信后验=主动受害。问题不在排序，在**校准**（high-confidence 对应训练集过代表的伪模式，OOD 系统性失效）。
2. **加强先验/表示不解决，反而恶化（F-R9.5）**。换 512-d MOMENT embedding 让后验更尖锐也更错（−0.80→−3.96pp）。
   根因是**元监督太少（56–128 cell）**——贝叶斯后验在小样本元任务上过拟合，再精的先验也救不了。
3. **meta-bandit 的"92% Thompson"疑似学环境噪声非决策质量**（M1 ablation 质疑）；且**饱和域后验必然坍缩到 base**，
   贝叶斯机器在"恒选 base 最优"的分布上不产生任何边际价值。

**改用什么 / 为什么更对**：从"信一个学出来的后验"→**解耦 confidence(选谁) 与 trust(信不信这次)**，
并用 **conformal nonconformity** 估 trust。conformal 是**分布无关、天然校准**的——恰好补上贝叶斯后验缺的那一环（校准）。
实证：10-clf 库上 conformal Trust-AUC 0.796，远高于集成内部分歧 0.55（F-R11.6）。

## 5. 为什么偏离"反事实记忆"

早期/候选范式：**clf_memory** —— 跨序列记住"哪个模型在哪类 cell 赢"（potential outcome Y(a)），
检索相似历史 cell 复用其 winner；以及 Round 12 #103 的**反事实/投资组合**方向（预测各候选 outcome 分布→加权配比）。

**放弃的三条实证理由**：

1. **记忆 winner 会泄漏，去泄漏后收益消失**。v3_memory 离线看 +0.89pp，但那是记忆含被测域的**泄漏假象**；
   honest 版立刻回落 **−0.62pp**（[[finding_cv_calibration_negative]] 同源教训）。
2. **反事实/组合实测输给单 base（F-R12.3）**。把"选一个"换成"按 Y(a) 分布加权组合"，最好的线性上界也 **−0.14pp**，
   gain-weighted **−3.6pp**——**饱和库里没有值得分散的互补专家结构**（Rocket 太强，掺弱模型只稀释）。
3. **反事实记忆要估计的那个量（per-cell gain / Y(a)）本身不可学（F-R12.1/12.2）**。
   gain 幅度弱可回归（corr 0.40）但"是否获利"分类失败（AUC 0.47），预测域 17% 头寸也吃不到。
   记不可学的量、检索不可迁移的 winner，自然不产生价值。

**改用什么 / 为什么更对**：放弃"记住并重放细粒度反事实结果"，改为**只预测粗粒度、可学的信号**——
saturation-headroom 决定 go/no-go，conformal 兜住损害。即**用对的信号干对的事**，而不是去估一个数据证明估不准的量。

## 6. +0.00pp 到底是什么意思：是"饱和 artifact"还是真结论？（关键审视）

**Q（导师/审稿人必问，也是我们自我审视的核心）：如果一直就那几个模型、数据集也固定，那么一旦某个模型在这些数据集上饱和，"路由不如直接用它"几乎是同义反复——所以 +0.00pp 会不会只是"窄库 + 选数据集"的循环 artifact？**

**A：这个质疑完全成立，并促使我们把库扩到 22 个、把结论从"饱和"修正为更强、非循环的"头寸真实但不可预测"。下面是审计证据。**

**① 旧的"饱和"框架确实有窄库 artifact 成分（已证、已修）**：

| 库规模 | rocket 即 oracle 比例 | oracle gap |
|---|---|---|
| 5 分类器（旧，F-R9.7）| **71%** | 1.88pp |
| **22 分类器 / 38 数据集（全 228 cell 全跑完，2026-06-06）** | **24.4%** | **5.95pp**（中位 3.00pp）|

扩到全量库后：oracle winner 由 **21/22 个模型分摊**（rocket 仅 54 cell=24% / muse 23 / minirocket 20 / rocket_mv 14 / multirocket 13 / fcn 11 …），**22/38 数据集 top 模型不是 rocket**（SonyAIBO→fcn 全胜、Ford/Wafer→weasel、BeetleFly→moment_1nn…）。→ **rocket 远非"通杀"（只赢 1/4 格），expert-switching 真实，oracle 头寸 5.95pp 也真实**（含真·远程大 TSFM chronos2/timesfm/timer 全 228 cell 真实推理）。所以"base 已是 oracle 故无需路由"在全量库上**彻底不成立**——旧框架那部分确是窄库 artifact。

**② 但决策仍 +0.00pp——真正的原因不是"没头寸"，是"头寸不可预测"**：

用部署可得特征（无 test）做 LODO 预测"逐-cell 谁赢"：

| 预测器 | winner 命中率 | 选"预测赢家"实测 vs base |
|---|---|---|
| 永远选 rocket（对照）| 0.204 | 0.00pp |
| 4 维系统特征 | 0.249 | **−0.25pp** |
| 30 维序列统计特征 | **0.113** | **−4.64pp**（更差）|

**头寸 REAL = 5.95pp，但照预测去抓 = 负收益**；而且**特征越丰富越差**（30 维过拟合，跌到 0.113 < 永远猜 rocket）。→ 谁赢主要由**少样本噪声 / 换种子就变**驱动，不是稳定的"A 模型配 B 类数据"映射。这与早期 F-R9.5（换 512 维 MOMENT embedding 更差）一致，但**现在是在全 228 cell 全跑完、真正多样的 22 模型库（含真远程大 TSFM）上得到的，不再是窄库假象**。

**③ 因此 +0.00pp 的正确解读（非循环）**：
不是"强 base 饱和到无可路由"，而是 **"可达天花板 ≠ 逐-cell 可预测"**——
oracle 头寸客观存在（5.95pp，需事后才知道谁赢），但**部署时用任何离线特征都选不对**，照选反而亏（−0.25 ~ −4.64pp）。
双信号门因此收敛到守 base：它正确地在"有头寸但抓不到"处弃权，避免了裸路由的 −2.77/−4.64pp 损害。

**④ 仍诚实保留的局限（质疑里对的部分）**：
- 数据集仍是学术 UCR/UEA；"不可预测"是在**这些域 + 这些特征**下的结论，**工业盲测/在线域可能不同**。
- 候选库虽扩到 22，但仍偏"同质感知模型"（多为 kernel/distance/dict/deep 变体）；**真正异构、结构互补的资产池**（不同物理先验）是否会出现"可预测的稳定专长"，是未验证的开放问题。
- → 这两条正是 §7"下一步"的方向：要拿正收益，换的是**域 / 资产池 / 在线反馈**，而非更多同质离线模型或更复杂的离线 confidence。

> 一句话：**你的质疑把结论从"窄库下的同义反复（饱和）"逼成了"宽库下的真问题（头寸真实但逐-cell 不可学）"——后者更强、可证伪、且非循环。** 复现见 `research/results/m22_threetask_phase.png`（三任务相图）+ 审计脚本（oracle-winner 分布 / 预测可达性）。

## 7. 一页结论

1. **这不是"没找到更好模型的失败"，而是"头寸真实但逐-cell 不可预测"下的正确决策**（§6 关键审视）：扩库到 22 个、全 228 cell 全跑完后 oracle 头寸 5.95pp 真实存在、rocket 仅 24.4% cell 最优（21/22 模型分摊），但用任何离线特征都预测不准谁赢（命中率 0.11~0.25，照选 −0.25~−4.64pp）→ 守 base 是诚实弃权，非"基线已饱和"的同义反复。
2. **三个负结果各有方法论价值**：belief inversion（别信后验强度）、gain 不可学（别估细粒度反事实）、组合输 base（饱和库无互补结构）——都是可证伪、领域无关的结论。
3. **一个正向机制结论（F-R12.5）**：决策的"避险"与"获利"是**两个需不同信号的子问题**，不能合并成一个万能 confidence/trust——避险用 conformal、获利用 saturation。
4. **落地稳定**：双信号解耦在 38 数据集（单变量+多变量）全量库上 +0.00pp、0 损害、决策可解释。

**下一步（要拿正收益需要的条件，非更复杂的离线 confidence）**：未饱和域（forecasting 主场）/ 真互补资产池 / 在线反馈信息增益。

## 附：

- **Q：既然 +0.00pp，价值在哪？** A：价值是**损害控制 + 可解释弃权**——裸 CV 路由 −2.77pp，本方法在更大更杂的库上稳定零损害；且这是对"强 base 何时已是 oracle"的可证伪刻画。
- **Q：贝叶斯不是更 principled 吗？** A：贝叶斯的 principle 依赖后验校准；本任务后验实测反校准（F-R9.2/9.5），conformal 的分布无关校准在这里更稳。
- **Q：为什么不继续做 gain model？** A：跨饱和/非饱和、跨分类/预测三路否证 gain 逐-cell 可学（F-R12.1/12.2），继续投入 ROI 为负；正路是换域/换资产池/上在线。
